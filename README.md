# Simple Sales Dashboard - Power BI Project

## Objective
Design an interactive dashboard in Power BI to visualize sales performance over time, by region, and by product category.

## Tools Used
- Power BI
- Sample Superstore Sales Dataset (2023)

## Dataset Fields
- Order Date
- Region
- Category
- Sales
- Profit
- Month-Year (derived column)

## Visuals Included
- **Line Chart**: Total Sales over each Month
- **Bar Chart**: Sales by Region
- **Donut Chart**: Sales by Category
- **Slicer**: Filter by Region
